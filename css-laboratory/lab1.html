My first CSS page

CSS, which stands for Cascading Style Sheets, is basically the language used to make websites look good. If you think of HTML as the skeleton and content of a webpage—like the text, links, and images—CSS is the clothing and design that gives it style. It lets you change things like background colors, fonts, text sizes, and where elements sit on the screen so a site doesn't just look like a boring plain text document. It also helps make sure a website adjusts properly whether someone is viewing it on a big laptop screen or a small phone.

What is the difference between inline, internal, and external CSS?

The main difference between inline, internal, and external CSS is where the styling code is placed and how much of a website it affects. Inline CSS is written directly inside a single HTML tag using the style attribute, so it only changes that one specific element. Internal CSS is placed inside a style tag in the head section of an HTML document, allowing you to style multiple elements across that single webpage at once. External CSS is written in a completely separate .css file and linked to your HTML pages, which is the most efficient method because changing that one file updates the design across an entire multi page website.
